Project 'house'
Authors: Michael Kölling and David J. Barnes
Modifiers: Asher Lanecki

This project is part of the material for the book

   Objects First with Java - A Practical Introduction using BlueJ
   Seventh edition
   David J. Barnes and Michael Kölling
   Pearson Education

It is discussed in chapter 1.
    
This is a very simple project to demonstrate some characteristics of
objects.

This project is often used after studying the "shapes" project. It
adds a class to those ones in "shapes". That class (named "Picture")
uses the shapes to draw a picture. It can be used to experiment with 
modifying source code.

This project was done in class and was my first experience with creating 
my own code and properly understanding what was being put in the source code. 
I enjoyed this experience because I had the freedom to do what I wanted after 
finishing what I needed to do. (example= made the person who moves after the 
sunset disappear after finishing the slowMoveHorizontal method while waiting 
for others to catch up)
